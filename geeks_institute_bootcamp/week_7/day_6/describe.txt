🟢 1. When the Dashboard Loads
orders = []
Empty array
No orders yet
UI shows: “No pending orders” (or just nothing)
➕ 2. User Clicks "Add Order" (First Time)

Event: onAddOrder

orders = ["Order #1"]
A new order is appended to the array
UI now shows:
Order #1 + "Mark as Served" button
➕ 3. User Clicks "Add Order" (Second Time)

Event: onAddOrder

orders = ["Order #1", "Order #2"]
Second order is added to the end (queue behavior)
UI shows:
Order #1
Order #2
❌ 4. User Clicks "Mark as Served" on First Order

Event: onServeOrder(orderId or index)

orders = ["Order #2"]
The first item is removed
Only remaining order stays in the list
⚙️ Conceptual Logic
Add Order
setOrders(prev => [...prev, newOrder])
Remove Specific Order
setOrders(prev => prev.filter(order => order.id !== idToRemove))
